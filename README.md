# Treino de Hipertrofia — Lucas Ribeiro

Site público do protocolo avançado de hipertrofia do aluno Lucas Ribeiro.

## Conteúdo

- Divisão semanal de cinco dias
- Séries, repetições, descanso e RIR
- Aquecimento específico por grupo muscular
- Plano B para cada exercício
- Links para exemplos visuais dos movimentos
- Controle local de exercícios concluídos

O site é estático e pode ser publicado diretamente pelo GitHub Pages.
